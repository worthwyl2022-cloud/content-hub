# Security and Evidence Policy

This repository contains documentation and presentation material. It is not an authority issuer, production control plane, or security certification.

Do not commit credentials, customer data, private keys, provider tokens, or unredacted diligence material. Report suspected exposure privately to the repository owner and include the commit, file path, and remediation recommendation.

Technical claims must link to implementation, tests, or reproducible evidence. Marketing language must not imply independent validation, compliance certification, or production readiness that is not present in the repository.
